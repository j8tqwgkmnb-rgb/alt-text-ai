Privacy Policy

Last updated: April 14, 2026

Alt Text AI ("we", "our", "the app") is a Shopify application developed by AccessAI. This policy explains what data we collect, how we use it, and your rights.

1. Data We Collect

When you install and use Alt Text AI, we access:

  • Product image URLs — to generate alt text descriptions
  • Product titles — to provide context for alt text generation
  • Shop domain — to track usage quotas

We do not collect personal customer data, payment information, order data, or any data unrelated to product images.

2. How We Use Your Data

  • Product image URLs are sent to the Anthropic API (Claude) to generate alt text descriptions
  • Product titles are included as context to improve description accuracy
  • Shop domain and monthly generation counts are stored to enforce usage limits

3. Third-Party Services

We use the following third-party services:

  • Anthropic API — for AI image analysis and alt text generation. Images are processed but not stored by Anthropic. See Anthropic's Privacy Policy.
  • Shopify — for app authentication and product data access. See Shopify's Privacy Policy.

4. Data Storage

  • Session data is stored in a SQLite database for authentication purposes
  • Monthly usage counts (shop domain + count) are stored to enforce free tier limits
  • We do not store product images or generated alt text — these are written directly to your Shopify store

5. Data Retention

Session data is retained while your app installation is active. Usage data is retained for the current billing period. Upon app uninstallation, all associated data is deleted.

6. Your Rights

You can:

  • Uninstall the app at any time to stop all data access
  • Request deletion of your data by contacting us
  • Review what data we hold by contacting us

7. GDPR Compliance

We comply with Shopify's mandatory GDPR webhooks for customer data requests, customer data erasure, and shop data erasure.

8. Changes

We may update this policy. Changes will be posted on this page with an updated date.
